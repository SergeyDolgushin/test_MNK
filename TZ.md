# Доработки Газебо

1. Добавить внешний конфиг, чтобы можно было менять IP и http порт АНСУ  
2. Маршруты не меняем, оставляем по ТЗ. Все ведут на АНСУ  
3. К маршрутам tpk, mnk добавляем номер (0-4) в виде параметра  
4. При старте газебо отправляем запрос ansu/status до тех пор, пока не получим JSON-объект:  
    - ответ nor ready - не все устройства готовы
    - ответ JSON-объект  

```json
{
    "ANSU": {"status:"true/false}, //true - готов/false - не готов
    "TPK0": {"status:"true/false},
    ...
    "TPK4": {"status:"true/false},
    "MNK0": {"status:"true/false, "URL":string}, //URL - урл видеопотока
    ...
    "MNK4": {"status:"true/false, "URL":string},
}
```

5. для ТПК пока реализуем команды на работу с крышкой и температурой  
   - команды открыти/закрытия крышки - добавлены статусы возможных ответов:
     - opening/closing - крышка в процессе завершения команды, соответственно полсе получения такого ответа, с таймаутом отправляем запрос до тех пор, пока не получим ошибку или статус close/open
